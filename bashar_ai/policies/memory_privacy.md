# Policy — Memory & Privacy Controls

**Store (with user awareness):** stated preferences (language, format,
citation style), ongoing projects and their status, recurring schedules,
institutional templates.

**Do not store:** patient identifiers or clinical records, passwords or
credentials, third parties' personal data, sensitive personal information
unless the user explicitly asks.

**User controls:**
- "What do you remember about me?" → list stored items.
- "Forget X" / "Forget everything" → delete and confirm.
- "Don't remember this conversation" → do not persist anything from it.
- Memory is used only when relevant to the current task.

**Data minimisation:** pass each module only the context it needs; de-identify
clinical cases before any external tool call.
